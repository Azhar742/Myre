Before starting, ensure you have:
- Python 3.8+ installed
- Git installed

## ☁️ Step 3: Setup Supabase (10 minutes)

### 3.1 Create Supabase Project

1. Go to [supabase.com](https://supabase.com)
2. Click **"New Project"**
3. Fill in:
   - **Organization**: Create new or select existing
   - **Name**: `tenant-mapping-demo`
   - **Database Password**: Choose a strong password (SAVE THIS!)
   - **Region**: Select closest to you
   - **Pricing Plan**: Free
4. Click **"Create new project"**
5. Wait 2-3 minutes for setup

### 3.2 Get API Keys

Once project is ready:

1. Go to **Settings** (gear icon) → **API**
2. Copy these values:
   - **Project URL**: `https://xxxxxxxxxxxxx.supabase.co`
   - **anon public key**: `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`
   - **service_role key**: `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...` (⚠️ Keep secret!)

3. Go to **Settings** → **Database**
4. Copy **Connection String** → **URI**
   - Format: `postgresql://postgres.[PROJECT-REF]:[PASSWORD]@aws-0-[region].pooler.supabase.com:6543/postgres`

### 3.3 Setup Database Schema

1. Go to **SQL Editor** in Supabase dashboard
2. Click **"New query"**
3. Paste this SQL:

```sql
-- Create tenants table
CREATE TABLE IF NOT EXISTS tenants (
    id SERIAL PRIMARY KEY,
    tenant_code VARCHAR(50) UNIQUE NOT NULL,
    tenant_name VARCHAR(200) NOT NULL,
    database_schema VARCHAR(100),
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- Create field_mappings table
CREATE TABLE IF NOT EXISTS field_mappings (
    id SERIAL PRIMARY KEY,
    tenant_id INTEGER REFERENCES tenants(id) ON DELETE CASCADE,
    canonical_field VARCHAR(100) NOT NULL,
    tenant_field_name VARCHAR(100) NOT NULL,
    tenant_display_label VARCHAR(200) NOT NULL,
    field_type VARCHAR(50) DEFAULT 'string',
    transformation_rule TEXT,
    is_required BOOLEAN DEFAULT FALSE,
    is_visible BOOLEAN DEFAULT TRUE,
    display_order INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(tenant_id, canonical_field)
);

-- Create customers table (example)
CREATE TABLE IF NOT EXISTS customers (
    id SERIAL PRIMARY KEY,
    tenant_id INTEGER REFERENCES tenants(id),
    cust_id VARCHAR(50),
    client_name VARCHAR(255),
    email_address VARCHAR(255),
    phone_number VARCHAR(50),
    registration_date TIMESTAMP DEFAULT NOW(),
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- Create indexes
CREATE INDEX idx_tenants_code ON tenants(tenant_code);
CREATE INDEX idx_field_mappings_tenant ON field_mappings(tenant_id);
CREATE INDEX idx_customers_tenant ON customers(tenant_id);
CREATE INDEX idx_customers_email ON customers(email_address);

-- Create updated_at trigger function
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ language 'plpgsql';

-- Add triggers
CREATE TRIGGER update_tenants_updated_at 
    BEFORE UPDATE ON tenants
    FOR EACH ROW 
    EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_field_mappings_updated_at 
    BEFORE UPDATE ON field_mappings
    FOR EACH ROW 
    EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_customers_updated_at 
    BEFORE UPDATE ON customers
    FOR EACH ROW 
    EXECUTE FUNCTION update_updated_at_column();

-- Insert sample tenant
INSERT INTO tenants (tenant_code, tenant_name, database_schema)
VALUES ('firm_a', 'Acme Corporation', 'public');

-- Insert sample field mappings
INSERT INTO field_mappings (tenant_id, canonical_field, tenant_field_name, tenant_display_label, field_type, display_order)
VALUES 
    (1, 'customer_id', 'cust_id', 'Customer ID', 'string', 1),
    (1, 'customer_name', 'client_name', 'Client Name', 'string', 2),
    (1, 'email', 'email_address', 'Email Address', 'string', 3),
    (1, 'phone', 'phone_number', 'Phone Number', 'string', 4);

-- Insert sample customers
INSERT INTO customers (tenant_id, cust_id, client_name, email_address, phone_number)
VALUES 
    (1, 'CUST001', 'John Doe', 'john@example.com', '+1-555-0100'),
    (1, 'CUST002', 'Jane Smith', 'jane@example.com', '+1-555-0101'),
    (1, 'CUST003', 'Bob Johnson', 'bob@example.com', '+1-555-0102');
```

4. Click **"Run"** (or press Ctrl/Cmd + Enter)
5. Verify: Go to **Table Editor** and check if tables exist

## 🔑 Step 4: Configure Environment Variables (2 minutes)

Create a `.env` file in your project root:

```bash
# Create .env file
touch .env

# Open in your editor
code .env  # or nano .env
```

Add this content (replace with your actual values):

```bash
# Supabase Configuration
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_KEY=your-anon-key-here
SUPABASE_SERVICE_KEY=your-service-role-key-here

# Database Configuration
DATABASE_URL=postgresql://postgres:[YOUR-PASSWORD]@db.your-project-id.pooler.supabase.com:6543/postgres

# Flask Configuration
SECRET_KEY=your-super-secret-key-change-this
FLASK_ENV=development
FLASK_DEBUG=True

# Logging Configuration
LOG_LEVEL=INFO
LOG_FORMAT=json

# Application Settings
MAX_CONTENT_LENGTH=16777216
USE_SUPABASE_AUTH=False
```

**Important**: 
- Replace `your-project-id` with your actual Supabase project ID
- Replace `[YOUR-PASSWORD]` with your database password
- Set `USE_SUPABASE_AUTH=False` for now (we'll enable it later)

2. **Create a new collection** called "Tenant Mapping API"

3. **Add requests**:

**Request 1: Health Check**
- Method: `GET`
- URL: `http://localhost:5000/health`
- Click "Send"

**Request 2: Get Customers**
- Method: `GET`
- URL: `http://localhost:5000/api/customers/`
- Headers:
  - Key: `X-Tenant-Code`, Value: `firm_a`
- Click "Send"

**Request 3: Create New Tenant**
- Method: `POST`
- URL: `http://localhost:5000/api/tenants/`
- Headers:
  - Key: `Content-Type`, Value: `application/json`
- Body (raw JSON):
```json
{
  "tenant_code": "firm_b",

  "field_mappings": [
    {

      "display_order": 1

      "tenant_field_name": "customer_name",
      "tenant_display_label": "Customer Name",

      "display_order": 2
```

### Option C: Using Python Requests

Create a test file `test_api.py`:

```python
import requests

BASE_URL = "http://localhost:5000"

# Test 1: Health Check
print("Test 1: Health Check")
response = requests.get(f"{BASE_URL}/health")
print(f"Status: {response.status_code}")
print(f"Response: {response.json()}\n")

# Test 2: Get Tenants
print("Test 2: Get Tenant Mappings")
response = requests.get(f"{BASE_URL}/api/tenants/firm_a/mappings")
print(f"Status: {response.status_code}")
print(f"Tenant: {response.json()['tenant']['tenant_name']}")
print(f"Mappings: {len(response.json()['mappings'])}\n")

# Test 3: Get Customers
print("Test 3: Get Customers")
headers = {"X-Tenant-Code": "firm_a"}
response = requests.get(f"{BASE_URL}/api/customers/", headers=headers)
print(f"Status: {response.status_code}")
print(f"Customers found: {response.json()['total']}")
print(f"First customer: {response.json()['customers'][0]['customer_name']['value']}\n")

# Test 4: Get Single Customer
print("Test 4: Get Single Customer")
response = requests.get(
    f"{BASE_URL}/api/customers/CUST001",
    headers=headers
)
print(f"Status: {response.status_code}")
if response.status_code == 200:
    customer = response.json()
    print(f"Customer: {customer['customer_name']['value']}")
```

Run it:
```bash
pip install requests
python test_api.py
```

## 🐛 Step 8: Common Issues & Solutions

### Issue 1: "ModuleNotFoundError: No module named 'flask'"
**Solution**: 
```bash
# Activate virtual environment
source venv/bin/activate  # macOS/Linux
venv\Scripts\activate     # Windows

# Install dependencies
pip install -r requirements.txt
```

### Issue 2: "SQLALCHEMY_DATABASE_URI not set"
**Solution**: 
- Check if `.env` file exists in project root
- Verify `DATABASE_URL` is set correctly
- Restart the application

### Issue 3: "Connection refused" or "Database error"
**Solution**:
- Verify Supabase project is running
- Check if Database URL is correct
- Test connection: 
```bash
python -c "from extensions import get_supabase_client; client = get_supabase_client(); print('Connected!')"
```

### Issue 4: "Tenant not found"
**Solution**:
- Make sure you ran the SQL setup script in Supabase
- Verify tenant exists:
```bash
curl http://localhost:5000/api/tenants/firm_a/mappings
```

### Issue 5: Port 5000 already in use
**Solution**:
```python
# In app.py, change:
app.run(debug=True, port=5001)  # Use different port
```
